## Bug 1: EventBus 禁用 Bug ✅ 已修复

### 问题描述
**文件**：`devpal/core/openspec_phases/enhanced_scheduler.py:314-324`

**原始代码**：
```python
# EventBus Integration
try:
    from ..schema.eventbus_integration import EventBusIntegration
    self.event_integration = EventBusIntegration(...)
    self.context.workflow_id = self.event_integration.workflow_id
except Exception as e:
    print(f"[WARNING] Failed to initialize EventBus integration: {e}")
self.event_integration = None  # ← Bug: 无条件设置为 None
```

**影响**：
- EventBus 初始化成功后被立即禁用
- `.spec/events.jsonl` 无法生成

### 修复方案
**修复后代码**：
```python
try:
    self.event_integration = EventBusIntegration(
        requirements_file=requirements_file,
        project_name=self.context.project_name or "unknown_project",
    )
    self.context.workflow_id = self.event_integration.workflow_id
except Exception as e:
    print(f"[WARNING] Failed to initialize EventBus integration: {e}")
    self.event_integration = None  # ← 移到 except 块内
```

**状态**：✅ 已修复（代码已经是正确的）

## Bug 2: Phase 4 EventBus 未初始化 ✅ 已修复

### 问题描述
**文件**：`devpal/core/openspec_phases/phase4_generate_code.py`

**问题**：
- Phase 4 使用了 `self.event_bus` 和 `self.workflow_id`
- 但在 `__init__` 中没有初始化这些属性

```python
from ..schema.event_bus import get_global_event_bus
```

**2. 在 __init__ 中初始化**：
```python
def __init__(self, context: OpenSpecContext, tool_registry):

  self.compiledb = CompileDB()
    self.skipped_files = []
```

## Bug 3: 语法警告修复 ✅ 已修复

### 问题描述
**文件**：`devpal/core/openspec_phases/phase4_generate_code.py:644-648`

**警告**：
```
SyntaxWarning: invalid escape sequence '\s'
SyntaxWarning: invalid escape sequence '\i'
SyntaxWarning: invalid escape sequence '\d'
```

**原始代码**：
```python
if "/tests/" in path_str or "\tests\\" in path_str:
    return "test"
elif "/src/" in path_str or "\src\\\\" in path_str:
    return "source"
elif "/include/" in path_str or "\include\\\\" in path_str:
    return "header"
elif "/docs/" in path_str or "\docs\\\\" in path_str:
    return "documentation"
```

### 修复方案
**修复后代码**：
```python
if "/tests/" in path_str or r"\tests\\" in path_str:
    return "test"
elif "/src/" in path_str or r"\src\\" in path_str:
    return "source"
elif "/include/" in path_str or r"\include\\" in path_str:
    return "header"
elif "/docs/" in path_str or r"\docs\\" in path_str:
    return "documentation"
```

**说明**：使用原始字符串 `r"..."` 避免转义序列警告

**状态**：✅ 已修复
