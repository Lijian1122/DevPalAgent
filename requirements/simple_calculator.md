# 极简计算器需求

## 项目概述
实现一个简单的加法计算器。

## 功能需求

### REQ-001: 加法功能
- 实现一个 add 函数
- 输入：两个整数 a 和 b
- 输出：返回 a + b 的结果

## 核心类设计

### Calculator（计算器类）
- 方法：int add(int a, int b)

## 技术约束
- C++17 标准库
- 不使用第三方库
- 提供 src/calculator.cpp 和 include/calculator.h
- 提供 src/main.cpp 演示
- 提供 tests/test_calculator.cpp 测试文件
