### 1. ✅ 多模态图片分析能力
**文件**: `devpal/multimodal/image_analyzer.py`

功能：
- 编译错误截图分析（提取错误代码、文件路径、行号、修复建议）
- 代码截图分析（提取代码内容、初步分析）
- 自定义提示词分析模式
- 批量图片分析支持

使用示例：
```python
from devpal.multimodal import ImageAnalyzer

analyzer = ImageAnalyzer()

# 分析编译错误截图
result = analyzer.analyze_compiler_error("screenshot.png")
print(result)

# 分析代码截图
result = analyzer.analyze_code_screenshot("code_screenshot.png")
print(result)
```

### 2. ✅ Git 自动化工具
**文件**: `devpal/tools/git_tool.py`

功能（共 9 种操作）：
| 操作 | 描述 |
|------|------|
| `status` | 查看仓库状态 |
| `add` | 添加文件到暂存区 |
| `commit` | 提交代码 |
| `diff` | 查看代码差异 |
| `branch` | 分支管理（list/create/delete）|
| `checkout` | 切换分支 |
| `log` | 查看提交历史 |
| `pull` / `push` | 拉取/推送代码 |
| `review` | 代码审查（委托给独立 code_review 工具） |
| `stash` | 暂存更改 |

使用示例：
```python
from devpal.tools import registry

# 查看状态
result = registry.execute_tool('git_tool', {'action': 'status'})

# 代码审查
result = registry.execute_tool('git_tool', {
    'action': 'review',
    'review_scope': 'changed'
})
```

### 3. ✅ 静态分析工具（clang-tidy / cppcheck）
**文件**: `devpal/tools/static_analyzer.py`

功能：
- 支持 clang-tidy 和 cppcheck 两种分析器
- 可指定具体检查规则（如 readability-*, performance-*）
- 按严重程度统计（error/warning/note/performance/style）
- 支持单文件或整个项目分析
- 自动修复（fix）功能（clang-tidy）

使用示例：
```python
from devpal.tools import registry

# 分析单个文件
result = registry.execute_tool('static_analyzer', {
    'action': 'analyze',
    'tool': 'clang-tidy',
    'file_path': 'src/main.cpp',
    'checks': '*'
})

# 查看可用分析工具
result = registry.execute_tool('static_analyzer', {
    'action': 'list_supported'
})
```

### 4. ✅ 独立代码审查工具
**文件**: `devpal/tools/code_review.py` ✨ 新增

功能：
- 支持多语言：C/C++、Python、JavaScript/TypeScript
- 5 种检查类别：todo、debug、style、security、performance
- 结构化输出（文件、行号、严重程度、类别、消息、修复建议）
- 支持单文件、目录递归、文件列表三种审查模式
- 可配置最大审查文件数限制

检查项：
| 类别 | 检查内容 |
|------|---------|
| `todo` | 检测 TODO/FIXME 注释 |
| `debug` | 检测调试代码（print/cout/console.log 等） |
| `style` | 检测魔法数字 |
| `security` | 检测不安全函数（strcpy/gets/eval）、潜在硬编码密钥 |
| `performance` | 检测裸指针使用（C++） |

使用示例：
```python
from devpal.tools import registry

# 单文件审查
result = registry.execute_tool('code_review', {
    'file_path': 'src/main.cpp',
    'check_types': ['todo', 'debug', 'security']
})

# 目录递归审查
result = registry.execute_tool('code_review', {
    'directory': 'devpal/tools/',
    'max_files': 50
})
```

### 5. ✅ MSVC 编译 + AddressSanitizer 工具
**文件**: `devpal/tools/msvc_asan_compiler.py` ✨ 新增

功能：
- Windows 平台 MSVC 编译器集成
- 内置 AddressSanitizer 支持（内存错误检测）
- 自动编译标志配置（/fsanitize=address /Zi /Od /EHsc /MDd）
- 支持自定义包含目录、库目录、链接库
- 编译后自动运行可选
- 集成编译错误解析

使用示例：
```python
from devpal.tools import registry

# 编译并启用 ASAN
result = registry.execute_tool('msvc_asan_compiler', {
    'source_files': 'main.cpp utils.cpp',
    'output_exe': 'myapp.exe',
    'include_dirs': 'include',
    'lib_dirs': 'lib',
    'libraries': 'user32.lib',
    'enable_asan': True,
    'run_after_build': False,
    'timeout': 60
})
```

### 代码调用
```python
from devpal.core import AgentEngine, AgentConfig
from devpal.tools import registry

# 创建 Agent
config = AgentConfig(enable_planning=True, enable_reflection=True)
agent = AgentEngine(config=config)

# 执行代码审查
result = agent.run("帮我审查 devpal/tools 目录下的所有 Python 文件")

# 编译代码
result = agent.run("用 MSVC 编译 src/main.cpp 并启用 AddressSanitizer")
```
